fluxo de execução

Como funciona

01
📝
Cola o código
Editor com syntax highlighting direto no browser. Cola seu bot Python, ajusta o requirements.txt.
02
🔐
Adiciona os secrets
DISCORD_TOKEN e outras variáveis ficam no backend. Nunca aparecem nos logs nem no frontend.
03
▶
Clica START
O backend cria um container Docker isolado, instala as deps, executa o main.py.
04
📴
Fecha o celular
O container continua rodando no servidor. Nada depende do seu browser.
05
🔄
Volta quando quiser
O dashboard reconecta via WebSocket e mostra o status atual + logs recentes.
06
⟳
Atualiza o código
Edita no editor, clica RESTART. O container antigo para, o novo sobe com o código novo.

funcionalidades

O que tem dentro

🟢
START / STOP / RESTART
Controle total do processo com um clique. RESTART salva o código novo e reinicia o container automaticamente.
📺
Terminal em tempo real
Todos os print(), erros e tracebacks aparecem no terminal com timestamp. Auto-scroll, copy, clear.
🔐
Variáveis de ambiente
Secrets ficam no backend. Injetados como env vars no container. Nunca expostos nos logs.
📦
requirements.txt automático
Cola suas dependências e o sistema instala no container antes de executar. Ambiente isolado por projeto.
⟳
Auto-restart
Se o bot crashar, reinicia automaticamente. Configura o limite de tentativas para não entrar em loop infinito.
📊
Stats ao vivo
CPU%, RAM, uptime, container ID e contagem de restarts atualizados em tempo real a cada 5 segundos.
🔒
Isolamento total
Cada projeto roda em container separado com cap_drop ALL, sem privilégios, usuário sandbox não-root.
👤
Multi-usuário
Auth com JWT + bcrypt. Cada usuário vê só os próprios projetos. Suporta múltiplos bots por conta.
📱
Mobile first
Interface responsiva. Editor de código, terminal e controles funcionam no iPhone e Android.

instalação

Rodando em 3 passos

🐳 Self-hosted (Docker)
1
Clone o repo e entre na pasta:
git clone ... && cd pycloud
2
Configure as variáveis:
cp .env.example .env
Edite .env — mude POSTGRES_PASSWORD e SECRET_KEY.
3
Sobe tudo:
./build.sh
Acesse http://localhost:3000
🤖 Discord bot (exemplo)
1
Cola este código no editor:
import discord
import os

client = discord.Client(
  intents=discord.Intents.default()
)

# on_ready, on_message etc.

client.run(os.getenv("DISCORD_TOKEN"))
2
Em requirements.txt:
discord.py
3
Em Settings → Env Vars:
DISCORD_TOKEN = seu_token
4
Clica START — bot online 🟢
